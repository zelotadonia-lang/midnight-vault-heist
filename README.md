The Midnight Vault is a top-down stealth game in a museum gallery after closing. You play Wren, a thief slipping past three patrolling guards and two sweeping cameras to steal the Star Sapphire from the vault, pocket three artifacts on the way out, and leave through the green EXIT. Smoke pellets blind every eye for a few seconds, an EMP pulse kills nearby cameras, and a holo-decoy pulls the nearest guard away to look at a double of you — one charge, spent on the moment that matters. Sneaking halves how fast the guards notice you. Push the alarm to 100 and the museum locks down: every guard hunts. The guards talk as they patrol, a minimap keeps the whole gallery in view, hints teach the ropes the first time each danger shows up, and a clean run earns a grade from Ghost to Loud. The score pays for loot, speed, and staying quiet. No libraries, no build step, no network: open game/index.html through any static server and play.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
